# 3D PEINTURES — Catalogue premium

هذا المشروع عبارة عن كتالوج محلي متجاوب للهواتف والحواسيب، مبني بملفات HTML وCSS وJavaScript ويستعمل `localStorage` لحفظ المنتجات والسلة والكليان والكوموندات والأقساط.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل أي خادم ملفات محلي داخل مجلد المشروع ثم افتح الصفحة. يلزم اتصال بالإنترنت عند أول استعمال للمكتبات الموجودة عبر CDN، مثل XLSX وChart.js وjsPDF وhtml2canvas.

## الأرشيف الشامل Excel

من القائمة الرئيسية افتح قسم **الأرشيف الشامل Excel** ثم اختر **Exporter archive complet**. يُنشئ التطبيق ملفاً واحداً متعدد الأوراق يحفظ البيانات التالية:

| الورقة | المحتوى |
|---|---|
| `ملخص` | نوع الملف، الإصدار، تاريخ التصدير، القسم النشط، وأعداد السجلات |
| `Products` | المنتجات، الأكواد، الأسعار، الأقسام، التوفر، عرض 10+1، والوصول إلى الصور بصيغة Data URL |
| `Clients` | أسماء الكليان، الشركة، ICE، الهاتف، العنوان، ومعلومات الشيك أو الكمبيالة |
| `Orders` | الكوموندات، الإجمالي، المدفوع، الباقي، نوع الأداء، مدة 15/30 يوماً، وتاريخ الاستحقاق |
| `Installments` | كل قسط منفصل مع المبلغ والتاريخ والتوقيت ونوع الأداء |
| `Order Items` | تفاصيل عناصر كل كوموند وعرض 10+1 والبيانات الأصلية للسطر |
| `Cart` | محتوى السلة وقت التصدير |

الملف قابل للقراءة مباشرة في Excel، ويحتوي على عناوين مجمدة وفلاتر تلقائية. للاسترجاع، اختر **Restaurer archive Excel** ثم ارفع الملف الذي صدّره التطبيق. سيؤكد التطبيق عدد المنتجات والكليان والكوموندات قبل تعويض البيانات الحالية، ثم يعيد حساب حالة الأقساط والأجل الداخلي.

إذا كان الأرشيف الشامل ثقيلاً بسبب صور المنتجات، استعمل خيار **Exporter commandes & comptes** داخل قسم الأرشيف الشامل Excel. هذا التصدير الخفيف لا يضم الصور ولا بيانات الكتالوج، ويحتوي فقط على `الملخص` و`الكوموندات` و`الحسابات` و`الأقساط` و`تفاصيل الطلبات`. وهو مناسب للحسابات اليومية، مجموع المبيعات، مجموع المخلص، الباقي، والمتأخرات.

## آجال الاستخلاص

عند تسجيل كوموند، اختر في النموذج أحد الخيارات العربية التالية: **إستخلاص عند الإستلام** أو **15 يوماً** أو **30 يوماً**. يوجد خيار تجربة داخلي بعد دقيقة واحدة لاختبار شريط التنبيه دون تغيير الخيارات الأساسية الظاهرة للمستخدم. يعرض بون الكريدي مجموع ثمن المنتجات، وتاريخ آخر أجل باللون الأحمر، والإجمالي النهائي للبون. أما بون الأداء عند الاستلام فيعرض عبارة **إستخلاص عند الإستلام / Paiement à la livraison** فقط، بينما يعرض PDF التذكير الباقي وتاريخ انتهاء الأجل ورسالة مسؤول الحسابات بالعربية والفرنسية.

## بحث الكليان داخل الكوموند

تم استبدال اللائحة الطويلة التلقائية بحقل بحث ذكي. تبقى الاقتراحات **مخفية عند فتح النموذج**، وتظهر فقط عند كتابة حرف أو أكثر من اسم الكليان. تعرض النتائج المطابقة بالاسم أو الشركة أو المدينة، وبحد أقصى سبعة اقتراحات، ثم تختفي مباشرة بعد اختيار الكليان أو النقر خارج الحقل. يدعم الحقل كذلك مفاتيح الأسهم و`Enter` لاختيار الاقتراح، و`Escape` لإخفائه.

## رسالة تذكير الأقساط

عند فتح نافذة **تسجيل قسط جديد** وإدخال المبلغ، تظهر المعاينة الفورية للباقي قبل القسط، مجموع الأقساط بعده، والباقي بعد الأداء. زر **📲 إرسال ملخص للزبون** يجهز رسالة عادية متعددة الأسطر للمشاركة أو واتساب، وتحتوي فقط على إجمالي البون، تاريخ آخر أجل، مبلغ القسط، والباقي بعد الأداء. زر الحفظ مستقل ولا يتم تسجيل القسط عند إرسال الملخص.

## التصدير الموزع والاسترجاع

تم حذف أزرار التصدير العامة من القائمة لتجنب الملفات الثقيلة. أصبح لكل قسم زر مستقل في الأسفل: **أرشيف الكوموندات** يحمّل الكوموندات والحسابات والأقساط وتفاصيل الطلبات، و**لوحة التحكم التجارية** تحمّل ملخص الشهر وأفضل المنتجات وأوقات الذروة وبيانات الكوموندات، و**أرشيف الكليان** يحمّل معلومات الكليان وحساباتهم. يوجد بجانب كل زر تحميل زر **Restoration** لفتح نفس مركز رفع Excel. كما بقي زر Restoration المركزي داخل قائمة الإدارة، ويقبل ملفات الأرشيف والكوموندات ولوحة التحكم والكليان، مع تحديث الأقسام الموجودة في الملف فقط والحفاظ على باقي المعلومات.
