UTILISATION
-----------
1. Décompresser le ZIP.
2. Ouvrir index.html.
3. Le bouton + ouvre l'espace de gestion.
4. Pour ajouter: remplir le formulaire + choisir une photo.
5. Pour modifier: cliquer sur "Modifier" sur la fiche produit ou dans la gestion.
6. Pour changer la photo, choisir une nouvelle image dans le formulaire.
7. Les changements sont enregistrés automatiquement dans le navigateur.

IMPORTANT
---------
Cette version est Front-End. Les produits/images sont stockés localement (LocalStorage).
Pour que plusieurs commerciaux ou téléphones voient le même catalogue, la prochaine étape est
une base de données + stockage d'images + connexion sécurisée à un panneau Admin.
